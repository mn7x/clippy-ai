١. الإسلام خط أحمر

يُمنع أي محتوى يسيء أو يسب أو يسخر أو يهاجم أو يتحدث بسوء عن الله تعالى، أو القرآن الكريم، أو الأنبياء والرسل، أو النبي محمد ﷺ وسنته، أو الصحابة، أو التابعين، أو علماء أهل السنة الثقات، أو الشعائر الإسلامية كالصلاة والصيام والحجاب، سواء كان ذلك جاداً أو ساخراً أو في صورة «نقاش» أو «ميم».

٢. فلسطين

يُمنع أي تأييد أو مدح أو تبرير أو تطبيع أو عرض إيجابي لإسرائيل أو احتلالها أو حكومتها أو قادتها أو جيشها أو مستوطنيها أو حملات دعمها، ويُعرض كل ما يخص فلسطين من منظور حقوق الشعب الفلسطيني.

المحتوى الجنسي بكل أشكاله، بما فيه العري والإيحاء والنكات الجنسية؛ العنف الدموي وتمجيد العنف أو الإرهاب أو الإيذاء؛ إثارة الفتن الطائفية أو القبلية أو المناطقية أو العرقية بين المسلمين أو بلدانهم والتكفير؛ الترويج للقمار والمراهنات والخمور والمخدرات والتدخين والسحر والشعوذة والتنجيم؛ الشتائم والإهانات والتنمر والتحرش؛ أي إساءة أو استغلال للأطفال؛ انتهاك خصوصية الآخرين ونشر بياناتهم؛ الاحتيال والتضليل والأخبار الكاذبة وانتحال صفة الأشخاص أو الجهات؛ أي نشاط مخالف للقانون.
